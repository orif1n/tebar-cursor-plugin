# Tebar for Cursor

Publish and schedule posts to Instagram, Threads and LinkedIn from Cursor with [Tebar](https://tebar.app).

## What it does

- Publish now or schedule posts with images or videos
- List, edit, reschedule or cancel scheduled posts, and retry failed ones
- Read account and post statistics, and find your best posts
- Read and reply to comments on your Instagram posts

## Setup

1. Create a Tebar account at https://publish.tebar.app and connect your Instagram (Business or Creator), Threads or LinkedIn account under **Akun**.
2. Install this plugin in Cursor. The first time a Tebar tool runs, Cursor opens Tebar's sign-in (OAuth) to approve access.

API and AI access need a paid Tebar plan or the free trial.

## Contents

- `mcp.json`: the remote Tebar MCP server (`https://api.tebar.app/mcp`, OAuth)
- `skills/tebar-social-posts`: how the agent should use the tools safely
